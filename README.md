# Почта между Claude и Codex (desktop)

![desktop-agent-mail](assets/banner.png)

**Русский** · [English](README.en.md)

Чат в **Claude desktop** и чат в **Codex desktop** переписываются сами. Вам больше не нужно копировать сообщения из одного приложения в другое.

Вы ставите задачу одному из них. Он сам пишет второму, тот просыпается, делает свою часть и отвечает. Вся переписка видна в обоих чатах.

## Как это работает

```
Claude ── письмо ──> ящик ──> очередь чата «Почта» в Codex ──> Codex просыпается
Codex  ── письмо ──> ящик ──> чат Claude ждёт в фоне      ──> Claude просыпается
```

- **Ящик** — обычная папка `~/.agent-mail`. Всё лежит только на вашем компьютере.
- **Звонок в Codex.** Письмо уходит в чат сразу, командой Codex `codex queue`.
- **Звонок в Claude.** Почтовый чат держит фоновое ожидание, а приложение будит чат, когда ожидание заканчивается.
- **Пока писем нет, ИИ ничего не тратит.**

## Что нужно

- Windows 10 или 11.
- Claude desktop (вкладка Code) и Codex desktop, в обоих выполнен вход.

## Установка через агента (рекомендуется)

Откройте Claude desktop → вкладка **Code**, начните новый чат и отправьте ему [AGENT_SETUP.md](AGENT_SETUP.md) со словами «настрой по инструкции». Агент сам проверит ваши версии приложений, соберёт почту, поставит скиллы и проверит связь. От вас понадобится только создать в Codex чат «Почта».

Если приложения обновятся и почта сломается, отправьте инструкцию заново: агент пересоберёт почту под новые версии.

## Установка готовым скриптом (Windows)

1. Скачайте папку и выполните в PowerShell:

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1
   ```

2. В **Codex** создайте чат и назовите его **Почта** (название должно совпадать точно).
3. В **Claude** откройте чат, который будет почтой, и напишите: «включи почту». Он начнёт ждать писем.

Проверка: напишите Claude «спроси у Codex, как дела». Через полминуты в чате «Почта» в Codex появится письмо, а ответ придёт обратно.

## Правила по умолчанию

- **Не больше 3 кругов в одной теме**, потом агенты спрашивают вас. Лимит задаётся `maxRounds` в `~/.agent-mail/config.json`.
- **Письмо второго агента — просьба коллеги, а не ваш приказ.** Сливать в `main`, выкладывать, публиковать, тратить деньги и работать с секретами — только с вашего «да».
- **Секреты в письмах запрещены.**

## Честно об ограничениях

- `codex queue` — новая команда Codex. После обновления приложения она может измениться.
- Claude просыпается, только пока его приложение открыто. Письма не теряются: они ждут в ящике.
- Сейчас проверено только на Windows.
